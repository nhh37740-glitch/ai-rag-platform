# AuthService 接口规范 0.5.1

本模块只依赖 DataServicePort、共享 AuthPrincipal/RequestContext 与 auth-runtime。普通用户身份、notebook ACL 与全站额度由本模块决策；SQLite 及事务由注入的 DataService 提供。

~~~python
class AuthService:
    def __init__(self, data: DataServicePort, session_ttl_seconds: int = 43200,
                 daily_limit: int = 100): ...
    def initialize(self, ctx: RequestContext, admin_username: str, admin_password: str) -> None: ...
    def register(self, ctx: RequestContext, username: str, password: str) -> dict: ...
    def login(self, ctx: RequestContext, username: str, password: str) -> tuple[AuthPrincipal, str]: ...
    def authenticate_session(self, ctx: RequestContext, token: str) -> AuthPrincipal: ...
    def logout(self, ctx: RequestContext, token: str) -> None: ...
    def guest(self, ctx: RequestContext) -> AuthPrincipal: ...
    def authorize(self, ctx: RequestContext, principal: AuthPrincipal, permission: str) -> None: ...
    def allowed_notebooks(self, ctx: RequestContext, principal: AuthPrincipal,
                          available_ids: list[str], public_ids: list[str] = []) -> list[str]: ...
    def notebook_permissions(self, ctx: RequestContext, principal: AuthPrincipal,
                             notebook_id: str) -> list[str]: ...
    def authorize_notebook(self, ctx: RequestContext, principal: AuthPrincipal,
                           notebook_id: str, permission: str) -> None: ...
    def list_members(self, ctx: RequestContext, principal: AuthPrincipal, notebook_id: str) -> list[dict]: ...
    def list_share_targets(self, ctx: RequestContext, principal: AuthPrincipal, notebook_id: str) -> list[dict]: ...
    def set_member(self, ctx: RequestContext, principal: AuthPrincipal,
                   notebook_id: str, user_id: str, role: str) -> None: ...
    def remove_member(self, ctx: RequestContext, principal: AuthPrincipal,
                      notebook_id: str, user_id: str) -> None: ...
    def list_admin_users(self, ctx: RequestContext, principal: AuthPrincipal) -> list[dict]: ...
    def set_user_active(self, ctx: RequestContext, principal: AuthPrincipal,
                        user_id: str, active: bool) -> None: ...
    def reserve_query(self, ctx: RequestContext) -> dict: ...
    def quota_status(self, ctx: RequestContext) -> dict: ...
~~~

首次空库需有效 bootstrap 管理员凭据，并一次创建管理员与固定 guest；非空库不重置或覆盖用户。register 创建普通 active 用户，guest 不可注册或登录。每次解析 session/principal 时读取用户当前记录并拒绝已禁用账号。token 只保存在 AuthRuntime 的进程内存，最长 12 小时，禁止数据库 session 表。

Notebook owner 拥有 read/query/import_document/write/manage_members/manage_notebook；editor 可 read/query/import_document/write；viewer 和 fixed guest 仅 read/query。notebook_members 只接受 editor/viewer，guest 仅 viewer。全局管理员不隐式读取或管理私人 notebook。allowed_notebooks 只筛选 available_ids 中 owner/成员实际有权限的资源；public_ids 仅为兼容参数，不授予任何权限。分享目标返回 active 用户（包含固定 guest），不得返回凭据字段。

普通 active 用户和管理员都可创建自己的 notebook，guest 不可创建。manage_users 与 manage_models 仅全局管理员可用；全局管理员不隐式拥有 notebook 权限。未知权限和非法参数为 ValueError，身份无效、权限不足、凭据失效或额度耗尽为 PermissionError。配额统一通过 DataService reserve_site_quota/site_quota_used，默认北京时间每日 100 次并跨全部账号共享。
