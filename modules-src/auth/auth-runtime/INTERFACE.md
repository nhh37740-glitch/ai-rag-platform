# AuthRuntime 接口规范 0.5.0

仅依赖 core_specifications 与 Python 标准库。密码采用 scrypt（N=16384,r=8,p=1）；会话令牌由进程随机密钥签名并只保存在当前进程内存，进程重启后全部失效。

~~~python
class AuthRuntime:
    def __init__(self) -> None: ...
    def hash_password(password: str) -> str: ...
    def verify_password(password: str, encoded: str) -> bool: ...
    def issue_principal(ctx: RequestContext, user_id: str, role: str) -> AuthPrincipal: ...
    def validate_principal(ctx: RequestContext, principal: AuthPrincipal) -> bool: ...
    def issue_session(ctx: RequestContext, user_id: str, ttl_seconds: int) -> str: ...
    def resolve_session(ctx: RequestContext, token: str) -> str | None: ...
    def revoke_session(ctx: RequestContext, token: str) -> None: ...
~~~

会话 TTL 只能为 1 至 43200 秒。凭据错误使用统一拒绝结果；repr 不包含密钥、密码、哈希、principal proof 或会话令牌。此模块不访问持久存储，不含登录代理或迁移逻辑。
